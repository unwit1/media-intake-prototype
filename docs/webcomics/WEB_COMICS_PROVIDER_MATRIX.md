# Content-provider coverage

Assessed 2026-09-29. **Fixture** means tested on small synthetic layouts, not certified against every live site. **Generic** means the feed/recipe machinery can be configured; automatic platform coverage is not claimed. Reliability is an engineering assessment. No private/paid access is implemented.

| Source | Discovery / metadata | Archive / chapters | Updates / images | Method / auth | Implementation / reliability / tests | OSS / evidence / caveats |
|---|---|---|---|---|---|---|
| xkcd | Any xkcd URL; creator + native page title/date/alt/transcript | Numeric index; no invented chapters; lazy historical metadata | Latest JSON number; fetch only new entry JSON/images | [Official JSON](https://xkcd.com/json.html); public | Implemented; API fixture, missing #404 fixture; live metadata smoke recorded in handoff | Dosage, native API; interactive special strips may need manual supplementary assets |
| WEBTOON / LINE | Series/viewer `title_no`; public list title | Public episode list; `episode_no`; chapter title evidence only | Newest list page on later checks; ordered vertical panels | Public HTML; no paid/app access | Implemented public HTML adapter; list/viewer fixtures; medium/fragile | [Zehina](https://github.com/Zehina/Webtoon-Downloader), [gallery-dl](https://github.com/mikf/gallery-dl/blob/master/gallery_dl/extractor/webtoons.py); regions/languages differ; archive pagination limited to recognized next links |

The platform rows deliberately separate practical pathways from implemented coverage. Live challenges, missing images and unexpected HTML produce errors; a browser window or downloaded file is never taken as evidence that all platform content can be imported.
